### What I learned

I learned how to use Bootstrap 5 to create a gridded layout for the testimonials. I used a grid with nested rows to create the structure with 4 boxes of equal height on the left and a taller box on the right. I was able to make the grid less messy compared to some previous projects made with a library by utilizing Bootstrap's built-in padding and margin classes. 
```html
<div class="row">
  <div class="col-lg-9">
    <div class="row">
      <div class="col-lg-8 p-3">
```
